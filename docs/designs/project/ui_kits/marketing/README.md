# Marketing — UI kit

The public **marketing landing page** for Creator Commerce (extends the site-tree's T7
Content/landing template). Composed from DS components and the brand voice — the hero copy is
drawn from the product's welcome screen.

## Sections
- **Nav** — logo lockup, section links, Sign in + Get started.
- **Hero** — headline "The storefront built for creators.", subtext, dual CTA, trust line, and a stylized mini-dashboard product preview (not a screenshot).
- **Trust strip** — headline stats in the mono font.
- **Features** — six feature cards (storefront, Stripe checkout, protected downloads, AI product pages, analytics, customer profiles) with Phosphor icons.
- **How it works** — three numbered steps.
- **Pricing** — three tiers (Starter / Pro / Studio) with a **monthly ⇄ yearly toggle** that updates prices; Pro is highlighted.
- **CTA band** — teal full-width call to action with the logo mark.
- **Footer** — link columns + legal row.

Built on DS `Button, Card, Badge, Separator`. Open `index.html`. Sentence-case copy, mono
numerals, teal primary, big soft radii — consistent with the seller app and storefront kits.
